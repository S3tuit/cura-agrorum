# Receiver database files

This directory contains the SQLite schema source and its generated output:

- `schema_source.sql` is the handwritten input. It defines the immutable
  `database_metadata` singleton, controlled-lifecycle `receiver_instances`,
  and append-only `quarantined_communicator_states`; these exceptional tables
  intentionally do not use regular generated row mappings.
- `schema.sql` is generated by `../tools/generate.py` from
  `schema_source.sql` plus the enum and entity manifests. Do not edit it by
  hand.

After changing `schema_source.sql`, follow the generation and freshness-check
instructions in [`../tools/README.md`](../tools/README.md).

Fresh databases are created by
`cura_receiver.database_initializer.initialize_database()` from the exact
packaged `schema.sql`. The initializer verifies its generated fingerprint and
never overwrites or migrates an existing database.
