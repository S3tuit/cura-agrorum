# Receiver database files

This directory contains the SQLite schema source and its generated output:

- `schema_source.sql` is the handwritten input. It currently defines
  `database_metadata`.
- `schema.sql` is generated by `../tools/generate.py` from
  `schema_source.sql` plus the enum and entity manifests. Do not edit it by
  hand.

After changing `schema_source.sql`, follow the generation and freshness-check
instructions in [`../tools/README.md`](../tools/README.md).
